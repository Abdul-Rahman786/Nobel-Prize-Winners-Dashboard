# Nobel Prize Winners Dashboard (1901–2022)

This Power BI project visualizes the data of Nobel Prize winners from 1901 to the 2022. It provides interactive insights into:

- Number of Nobel Prize winners by **year**
- Winners grouped by **country** and **city of birth**
- Distribution by **gender** and **Nobel Prize category**
- Analysis of **average age at the time of winning**
- Historical trends and patterns over time

## Key Features
- Dynamic slicers and filters for deep dive analysis
- Colorful and informative charts for easy interpretation
- Highlights of top cities and countries with most laureates
- Clean and user-friendly layout

## Tools Used
- Power BI Desktop
- DAX
- Data modeling and cleaning

## Use Case
This dashboard can help researchers, students, and data enthusiasts explore historical trends in Nobel Prize distributions across the world.
